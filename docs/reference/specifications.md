# Canonical specifications

The task pages summarize behavior and point to the canonical documents. DocFX
includes those files directly from `specs/`, so they remain one source of truth
and do not need to be copied into `docs/`.

| Document | Scope |
| --- | --- |
| [SPEC](../../specs/SPEC.md) | Normative scope, core rules, and adapter boundary |
| [BUNDLE](../../specs/BUNDLE.md) | Ordered memberships, nesting, and ownership operations |
| [REFERENCES](../../specs/REFERENCES.md) | Reference envelopes, provenance, and public AT records |
| [OPML-PROFILE](../../specs/OPML-PROFILE.md) | Conventional and graph OPML profiles |
| [SECURITY](../../specs/SECURITY.md) | Resource resolution and rendering security |
| [CONFORMANCE](../../specs/CONFORMANCE.md) | Fixture-driven implementation levels |

The original source files are preserved. Use the generated local pages for
reading, and the repository's [source history](https://github.com/lqdev/at-resource-graph/commits/main/specs)
only when reviewing changes.
