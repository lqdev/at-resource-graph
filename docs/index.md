# AT Resource Graph

AT Resource Graph is a draft, protocol-aware resource graph for ordered
collections of RSS/Atom feeds, AT records, websites, and nested bundles.

This site is an early DocFX skeleton. Start with the normative
[specification](https://github.com/lqdev/at-resource-graph/blob/main/specs/SPEC.md),
then read the [bundle model](https://github.com/lqdev/at-resource-graph/blob/main/specs/BUNDLE.md),
[reference model](https://github.com/lqdev/at-resource-graph/blob/main/specs/REFERENCES.md),
and [security rules](https://github.com/lqdev/at-resource-graph/blob/main/specs/SECURITY.md).

The editorial profile is [ASD-STE100-inspired](editorial-profile.md). It
borrows a preference for clear, controlled technical language. It does not
claim ASD-STE100 compliance and does not reproduce ASD-STE100 text.

The current executable slice includes [public-read adapters](https://github.com/lqdev/at-resource-graph/blob/main/specs/SPEC.md#public-read-adapters)
and an offline [Reader reference surface](https://github.com/lqdev/at-resource-graph/blob/main/README.md). It does not include
OAuth, firehose ingestion, AppView deployment, or arbitrary URL fetching.
